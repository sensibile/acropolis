# 작업 기록 템플릿

이 템플릿을 작업별 로컬 Git common directory에 복사해 사용한다. 사용법과 기록 경계는 [작업 승인 기록과 PR 전달 절차](task-delivery.md)를 따른다. 미확인 값은 미확인으로 유지한다.

## 목적과 요청한 완료 상태

- 작업 ID / 목적: 미기록
- 요청 근거 / 대화 위치: 미기록
- 요청한 완료 상태: 미확인
- 실제 현재 상태 / 관찰 시각: 미확인
- 완료 판정에 필요한 관찰: 미기록

## 작업 위치

- 저장소 / worktree / branch: 미확인
- PR / 티켓: 미확인
- 원격 source/target SHA / 관찰 시각: 미확인
- PR head SHA / base / OPEN·MERGED·CLOSED / Draft 여부: 미확인

## 승인 기록

| 행위 | 대상과 데이터 범위 | 수신자·사용 방식 | 제약 | BOSS의 근거 문구·대화 위치 | 현재 유효 여부 |
| --- | --- | --- | --- | --- | --- |
| 미기록 | 미기록 | 미기록 | 미기록 | 미기록 | 미확인 |

승인이 없는 행위는 미승인으로 적는다. 철회나 범위 변경이 있으면 이전 기록을 보존하고 변경 근거를 추가한다. 비밀값을 넣지 않는다.

## 실행 경로와 결과

| 단계 | 사용할 도구·경로·대상 | 예상 성공 관찰 | 실제 결과·증거 위치 | 현재 상태 |
| --- | --- | --- | --- | --- |
| 미기록 | 미기록 | 미기록 | 미실행 | 미실행 |

## 실패와 다음 행동

- 실패한 단계 / 도구 오류 또는 검사 finding: 없음 또는 미확인
- 자동 승인 거절의 정확한 동작과 이유: 없음 또는 미확인
- 기존 승인과 거절의 관계: 미확인
- 확인한 원인 / 바뀐 입력: 미기록
- 유효한 이전 증거 / 무효가 된 증거와 이유: 미기록
- 다음 행동 / 필요한 새 정보: 미기록

## 전달 완료 확인

- post-code·diff·필수 검사 결과 / commit SHA: 미실행
- 적용 gate / 검토 base·head / 결과·seal 위치: 미실행
- push 결과 / 원격 head SHA: 미실행
- 일반 PR URL / 실제 head·base·Draft 여부: 미확인
- GitHub 검사 결과 / 관찰 시각: 미확인
- 앱 attach / 티켓 갱신 결과: 미실행 또는 해당 없음
- merge 결과: 미실행; PR 승인과 구분
- 요청 대비 남은 일: 미기록
